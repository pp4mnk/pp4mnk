# pp4mnk — EasyOS & Puppy Linux

Welcome! I share tools, scripts, customizations, guides and resources
for EasyOS and Puppy Linux.

My work is distributed across GitHub, SourceForge and Internet Archive.
This page connects those resources so you can explore more than my
GitHub repositories.
